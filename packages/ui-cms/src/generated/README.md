# Library Kit — @midas/ui-cms@2.7.2

This folder is generated by Midas from the **CMS Design System** library and overwritten on every `npx @midas/cli sync`. Do not edit it by hand: change the design in Midas, publish a new version, then sync.

- `theme.ts`, `tokens.css`, `tailwind-theme.css` — theme tokens from Variables
- `props/` — props contract of every component (used by the components in `src/components`)
- `icons/` — 30 React icons from the design system (`ArrowLeftIcon`, `<Icon name>`); colors follow `currentColor`
- `manifest.json` — component and props list for the Code Builder Properties Inspector
