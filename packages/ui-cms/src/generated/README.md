# Library Kit — @midas/ui-cms@1.1.1

Folder ini dibangkitkan oleh Midas dari library **CMS Design System** dan ditimpa setiap `npx @midas/cli sync`. Jangan diedit manual: ubah desain di Midas, publish versi baru, lalu sync.

- `theme.ts`, `tokens.css`, `tailwind-theme.css` — token tema dari Variables
- `props/` — kontrak props setiap komponen (dipakai komponen di `src/components`)
- `icons/` — 27 ikon React dari design system (`ArrowLeftIcon`, `<Icon name>`), warna ikut `currentColor`
- `manifest.json` — daftar komponen + props untuk Properties Inspector Code Builder
