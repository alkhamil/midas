# Library Kit — @midas/ui-base@1.0.0

Folder ini dibangkitkan oleh Midas dari library **Midas Base Design System** dan ditimpa setiap `npx @midas/cli sync`. Jangan diedit manual: ubah desain di Midas, publish versi baru, lalu sync.

- `theme.ts`, `tokens.css`, `tailwind-theme.css` — token tema dari Variables
- `props/` — kontrak props setiap komponen (dipakai komponen di `src/components`)
- `icons/` — 306 ikon React dari design system (`ArrowLeftIcon`, `<Icon name>`), warna ikut `currentColor`
- `manifest.json` — daftar komponen + props untuk Properties Inspector Code Builder
